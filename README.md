## Quickstart  
1. Go to the latest release. On GitHub, search for the Releases section on the panel on the right side.  
2. Search for executables on your platform.  
    - Windows: .zip (portable archive containing .exe).  
    - GNU+Linux: .zip (portable archive containing .x86_64).  
    - MacOS: .zip (portable archive containing .dmg).  
3. Download, extract, and enjoy!  

## Running / Editing from Source  
1. Clone this repo: `git clone https://github.com/gducpm/lichemy.git`  
2. Download [Godot Engine 4.x](https://godotengine.org/download/) for your platform.  
3. Open the Godot Project Manager, click **Import**, and navigate to the folder containing `project.godot`.  
4. Click **Edit** to view the source, or press **F5** to run the simulation!  

## Exporting / Building Binaries  
If you want to compile standalone executables yourself:  
1. Open the project in Godot 4.x.  
2. Go to **Project** > **Export...** from the top menu bar.  
3. Select the desired presets (Windows Desktop, Linux/X11, macOS). Note: You may be prompted to download Godot Export Templates if you haven't already.  
4. Click **Export Project** and choose your destination directory.
